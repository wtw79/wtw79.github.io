PROBLEM

解决现场的真实麻烦

在没有这套系统之前，从会前准备到会后收尾，几乎每个环节都依赖人工

会前准备

资料零散难管理

公告、图片、产权资料散落在纸质文件和表格里，现场换标的要翻半天资料，容易拿错。

会中展示

展示全靠手工布置

白板、纸质大字报，观众看不清、记不住，缺少现场仪式感。

会中竞价

报价记录靠手写

号牌与价格人工记录，容易记错、漏记，现场出现争议时说不清。

会后收尾

成交留档繁琐

报表靠人工整理、截图要手动保存，事后追溯靠翻文件，容易遗漏。

WORKFLOW

一场拍卖的完整流程

系统贴合现场真实节奏设计，不打断、不添乱

1

会前准备

  1. 标的管理中新增本场标的
  2. 完善起拍价、展示标题、公告 PDF、图片
  3. 确认大屏标题与表格样式
  4. 连接副屏，预览投屏效果
2

会中竞价

  1. 设为当前标的，打开欢迎页与竞价页
  2. 宣布起拍，点击"开始拍卖"
  3. 录入号牌，输入即提交，大屏实时更新
  4. 随时调整竞价幅度，落槌确认成交
3

会后收尾

  1. 核对成交记录
  2. 需要时导出 Excel
  3. 确认归档目录中的报表与截图
  4. 继续下一标的，或结束本场
