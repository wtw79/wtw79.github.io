核心作品 · 2021—至今

拍卖竞价显示系统

面向拍卖会现场的信息展示与竞价管理工具 · WPF / .NET 8 桌面应用
GitHub ↗

标的管理、大屏投屏、实时竞价、成交归档，一站式完成"从开场到落槌"的全过程。所有业务数据保存在本地，不依赖联网、不外传。

功能地图
📋
标的管理
新增/编辑/删除/设为当前，Excel 批量导入，各标的独立配置。
🎛️
控制台
号牌输入即提交，增价/降价随时切换，投屏状态实时预览。
🖥️
大屏展示
欢迎页公告+图片轮播，竞价页实时报价，支持多屏投屏。
📦
成交归档
一键生成 Excel 报表、保存现场截图，按标的带时间戳归档。
📊
报表管理
历史报表查看、记录撤回/删除、多页导出 Excel。
⚙️
系统设置
欢迎页文字/字体、竞价页表格结构、背景一键切换。
🔢
数字软键盘
无物理键盘时的报价录入方案，支持快速自定义按键。
🔒
本地数据留档
数据存于本地 AuctionData 目录，按标的自动归档，定期备份即可长期存档。
📡

投屏架构重构，刷新流畅，支持多副屏自由切换与动态分辨率适配。
一场拍卖的完整流程
01 / 会前准备

把资料管起来

  • 标的管理中新增本场标的
  • 完善起拍价、公告 PDF、图片
  • 确认大屏标题与表格样式
  • 连接副屏，预览投屏效果
02 / 会中竞价

把报价亮出来

  • 设为当前标的，打开欢迎页
  • 点击"开始拍卖"
  • 录入号牌，输入即提交
  • 调整幅度，落槌确认成交
03 / 会后收尾

把结果存下来

  • 核对成交记录
  • 按需导出 Excel
  • 确认归档目录报表与截图
  • 继续下一标的或结束本场
